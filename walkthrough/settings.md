# Settings

- `pcapViewer.timeFormat`: seconds since the first packet, seconds since the previous packet, or the date and time in UTC or local time. The Time menu in the toolbar changes it for one tab.
- `pcapViewer.resolveNames`: show host names from the capture (DNS answers and pcapng name blocks). Nothing is looked up on the network.
- `pcapViewer.savedFilters`: the filters in the star menu.
- `pcapViewer.maxGzipMB`: the largest size a `.gz` capture may unpack to (512 MB by default).
- `pcapViewer.maxRemoteMB`: the largest file read from a remote or virtual file system.
